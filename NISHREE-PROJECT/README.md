# VELORA — Launching Soon

A responsive fashion e-commerce “Coming Soon” landing page built with only HTML, CSS and vanilla JavaScript.

## Included
- Live launch countdown
- Editorial fashion hero section
- Responsive layouts for mobile, tablet and desktop
- Scroll-reveal animations
- Hover transitions and image zoom
- Animated marquee strip
- Full-screen navigation panel
- Email notification form demo
- Reduced-motion accessibility support
- No framework or build step required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Change launch date
Edit `LAUNCH_DATE` in `script.js`.

## Production note
The email form is front-end only. Connect it to your backend/email platform before production.
